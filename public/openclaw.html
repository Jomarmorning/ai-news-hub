Quick Start

全平台安装教程，10分钟完成 OpenClaw 部署

1

安装 Docker

确保已安装 Docker Desktop 或 Docker Engine

docker --version
2

拉取 OpenClaw 镜像

从 Docker Hub 获取最新版本

docker pull openclaw/openclaw:latest
3

启动容器

运行 OpenClaw Gateway 服务

docker run -d -p 18789:18789 --name openclaw openclaw/openclaw:latest
4

验证安装

检查服务是否正常运行

curl http://localhost:18789/health
💡

Pro Tip
